Personal Portfolio Website
A fully responsive personal portfolio website built with pure HTML, CSS, and JavaScript to showcase skills, projects, and professional experience.
🌐 Live Demo
Live URL: (https://dinda1112.github.io/portfolio_fely/)
📋 Project Overview
This portfolio website was created as part of an academic project with the objective of designing, coding, and deploying a professional portfolio using only vanilla web technologies. The site demonstrates core web development skills and showcases projects in a clean, accessible, and responsive interface.
✨ Features
Core Sections

Home - Landing page with introduction and call-to-action
Projects - Showcase of at least 3 projects with descriptions and links
About Me - Personal background, skills, and experience
Contact - Contact form and/or email link for professional inquiries

Technical Features

Responsive Design - Fully optimized for mobile, tablet, and desktop screens
Persistent Navigation - Easy-to-use navigation bar visible across all sections
Smooth Scrolling - Seamless internal navigation between sections
JavaScript Interactivity - Minimum of 3 interactive features (details below)
Accessibility - WCAG-compliant with proper alt text, contrast ratios, and focus states

🛠️ Technologies Used

HTML5 - Semantic markup and structure
CSS3 - Custom styling, flexbox/grid layouts, animations
JavaScript (Vanilla) - Interactive functionality and DOM manipulation

Constraints Followed
✅ No frameworks (Bootstrap, Tailwind, React, jQuery)
✅ No drag-and-drop builders (Wix, Notion, Framer, WordPress)
✅ No AI-assisted editors (Loveable, Replit Ghostwriter, CodePen AI)
✅ No cloud IDEs (Replit, Glitch, GitHub Codespaces)
✅ All code personally written, edited, and understood
